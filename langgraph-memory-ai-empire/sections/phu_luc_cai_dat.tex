\chapter{Cài đặt và lệnh chạy}
\label{app:setup}

\section{Cài môi trường}

Từ thư mục giáo trình:
\begin{lstlisting}[language=bash]
uv sync --extra dev
uv run pytest -q
\end{lstlisting}

Chạy từng ví dụ:
\begin{lstlisting}[language=bash]
uv run python code/manual_history.py
uv run python code/graph_basics.py
uv run python code/short_term_memory.py
uv run python code/long_term_memory.py
\end{lstlisting}

Chạy FastAPI lab:
\begin{lstlisting}[language=bash]
uv run uvicorn fastapi_app:app --app-dir code --reload
\end{lstlisting}

Mở \url{http://127.0.0.1:8000/docs} để chạy request bằng Swagger UI.

\section{Provider thật}

\begin{lstlisting}[language=bash]
uv sync --extra dev --extra providers
\end{lstlisting}

Đặt API key bằng biến môi trường hoặc file \texttt{.env} đã bị ignore; không commit secret. Adapter
tham khảo nằm ở \texttt{code/real\_model\_adapter.py}.

\section{Build PDF}

Máy có MiKTeX theo cấu hình repository chạy:
\begin{lstlisting}[language=bash]
.\build-latex.ps1
\end{lstlisting}

Output ở \texttt{build/main.pdf}. Build script dùng thư mục MiKTeX riêng của project và không ghi
đè các biến profile phổ biến.

\section{Fallback}

Nếu chưa cài được LangGraph, học chương 1 bằng \texttt{manual\_history.py}; nếu không có API key,
chạy toàn bộ test với model quyết định; nếu chưa có PostgreSQL, dùng InMemorySaver để hoàn thiện
logic rồi viết test contract cho backend sau.
