\chapter*{Kết luận}
\addcontentsline{toc}{chapter}{Kết luận}

Bộ nhớ hội thoại không bắt đầu ở vector database. Nó bắt đầu ở một hợp đồng đơn giản: mỗi message
thuộc đúng conversation; mỗi conversation thuộc đúng user; state được lưu có chủ đích; model chỉ
đọc lát context phù hợp. LangGraph cung cấp state graph, checkpointer và Store để biểu diễn hợp đồng
ấy, nhưng authorization, retention, schema memory và đánh giá chất lượng vẫn là trách nhiệm của
ứng dụng.

Lộ trình an toàn là: Python thuần để hiểu cơ chế; model quyết định để test; InMemorySaver để học
thread; database để có durability; trim trước summary; key-value trước semantic memory; provider
thật sau khi isolation đã xanh. Khi từng lát có test, việc thêm RAG, tool hoặc agent về sau không
làm mất nền móng hội thoại.

\begin{aicheckpoint}[Ba câu phải trả lời được]
\begin{enumerate}
  \item Dữ liệu nào đang được lưu, ở đâu và theo khóa nào?
  \item Lượt gọi model này thực sự nhận những message nào?
  \item Điều gì chứng minh user khác không đọc được state hoặc memory này?
\end{enumerate}
Nếu ba câu đều có câu trả lời và test quan sát được, hệ thống đã đi đúng hướng.
\end{aicheckpoint}
